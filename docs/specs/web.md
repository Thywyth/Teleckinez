# Специфікація: веб-панель

FastAPI на `http://localhost:8000`, фронтенд — статичні `index.html`, `app.js`,
`style.css` без збірки і без CDN (працює офлайн). Інтерфейс українською
(перемикач uk/en — P2). Світла і темна теми.

## 1. Екрани

1. **Дашборд** — картки пристроїв, згруповані за кімнатами: іконка, назва,
   стан наживо (вкл/викл, %, °C, рух штор як анімована смуга), індикатор
   доступності (online / stale / offline), ручне керування (кнопки/повзунки —
   ті самі команди через диспетчер, як голосом).
2. **Голосова панель** (бічна або верхня): індикатор стану конвеєра
   (очікування / слухаю / розпізнаю / говорю), кнопка push-to-talk, останній
   транскрипт з confidence і рушієм, розібраний намір, текстова відповідь,
   поле для текстової команди.
3. **Журнал команд** — таблиця з життєвим циклом кожної команди: статус,
   час кожного етапу (published → ack → completed, мс), помилки. Фільтри.
4. **Збої (симулятор)** — для кожного пристрою вибір збою (offline, freeze,
   stuck, slow, reject, drop_rate) — для демонстрації на захисті.
5. **Налаштування** — тригер (wake word vosk/openwakeword, push-to-talk),
   STT-рушій і мова, NLU-режим, TTS (голос+текст / лише текст), таймаути.
   Зміни застосовуються «на гарячу» без перезапуску, де можливо.
6. **Метрики** (P2) — короткі графіки затримок з SQLite за сесію.

## 2. API

| Метод | Шлях | Опис |
|---|---|---|
| GET | `/api/devices` | пристрої + двійник (reported, desired, availability) |
| POST | `/api/devices/{id}/command` | ручна команда `{action, params}` |
| POST | `/api/text-command` | текстова команда `{text}` → той самий шлях, що й голос |
| POST | `/api/voice/ptt` | `{pressed: true/false}` — push-to-talk з браузера |
| GET | `/api/commands?limit=` | журнал команд |
| GET/PUT | `/api/settings` | поточні налаштування / зміна |
| POST | `/api/sim/faults` | `{device_id, fault, params}` |
| WS | `/ws` | потік подій EventBus у JSON: `{type, ts, data}` |

Фронтенд при старті тягне `/api/devices`, далі живе лише з подій WebSocket.

## 3. Вимоги до вигляду

Панель потрапить на скріншоти записки, презентації і README → охайний
сучасний вигляд: сітка карток, читабельні шрифти, анімація зміни станів,
кольори статусів (зелений — completed/online, жовтий — pending/stale,
червоний — failed/offline). Для друку записки — скріншоти у світлій темі.
