# ПЕРЕЛІК УМОВНИХ ПОЗНАЧЕНЬ І СКОРОЧЕНЬ

::: {custom-style="Reference"}
ACK (acknowledgement) – підтвердження прийому команди пристроєм

ADR (Architecture Decision Record) – запис архітектурного рішення

API (Application Programming Interface) – програмний інтерфейс

CER (Character Error Rate) – частка помилок у символах

FA (False Accept) – хибне спрацювання детектора ключового слова

FRR (False Reject Rate) – частка хибних відмов детектора ключового слова

FSM (Finite-State Machine) – скінченний автомат

GPU (Graphics Processing Unit) – графічний процесор

IoT (Internet of Things) – інтернет речей

JSON (JavaScript Object Notation) – текстовий формат обміну даними

LLM (Large Language Model) – велика мовна модель

LWT (Last Will and Testament) – «останній заповіт», повідомлення, яке брокер MQTT публікує після обриву з'єднання клієнта

MQTT (Message Queuing Telemetry Transport) – протокол обміну повідомленнями «видавець – підписник»

NLU (Natural Language Understanding) – розуміння природної мови

QoS (Quality of Service) – рівень гарантії доставки повідомлення в MQTT

RTF (Real-Time Factor) – коефіцієнт реального часу

STT (Speech-to-Text) – розпізнавання мовлення

TTS (Text-to-Speech) – синтез мовлення

ULID (Universally Unique Lexicographically Sortable Identifier) – унікальний ідентифікатор, що сортується за часом

VAD (Voice Activity Detection) – виявлення голосової активності

WER (Word Error Rate) – частка помилок у словах
:::
